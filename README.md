# Visio 1 (MVP)

Petit MVP de visioconférence WebRTC (mesh) :
- Pas de login
- Salon via l’URL `?room=xxxx`
- Bouton **+** : active caméra/micro et rejoint la visio
- Signaling via **Socket.IO**
- UI responsive

## Prérequis
- Node.js (idéalement >= 18)
- npm

## Installation
Dans le dossier du projet :

```bash
npm install
